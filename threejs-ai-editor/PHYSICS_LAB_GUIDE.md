# 🧪 物理实验室使用指南

欢迎使用 AI 驱动的 3D 物理教育辅助平台！本指南将帮助您快速上手，创建精彩的物理学习体验。

## 🚀 快速开始

### 1. 安装依赖

```bash
cd threejs-ai-editor
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 访问物理实验室

打开浏览器访问：`http://localhost:3000/physics-lab`

### 物理参数控制

点击"参数控制"标签，实时调整物理参数：

#### 🌍 重力加速度 (0-20 m/s²)

- **地球标准**: 9.81 m/s²
- **月球重力**: ~1.6 m/s²
- **木星重力**: ~24.8 m/s²
- **实验建议**: 观察重力变化对下落速度的影响

#### 🤏 摩擦系数 (0-1)

- **无摩擦**: 0 (理想状态)
- **冰面**: ~0.1
- **干燥路面**: ~0.7
- **实验建议**: 调整摩擦观察滑动距离变化

#### ⚡ 弹性系数 (0-1.5)

- **完全非弹性**: 0
- **正常弹性**: 0.7
- **超弹性**: 1+
- **实验建议**: 改变弹性观察反弹高度

## 🔍 故障排除

### 常见问题

#### Q: 物理场景没有运动？

**A**: 检查物理引擎是否正确初始化，确保代码中包含 `world.step()` 循环。

#### Q: 物体穿过地面？

**A**: 确认地面有正确的刚体和碰撞器设置，检查碰撞器大小是否匹配视觉对象。

#### Q: AI 生成的代码报错？

**A**: 查看控制台错误信息，通常是缺少 RAPIER 参数或物理世界初始化问题。

#### Q: 参数调整没有效果？

**A**: 确保当前场景是物理场景，检查物理对象是否正确绑定到参数控制系统。

### 性能优化

1. **减少物体数量**: 单个场景建议不超过 20 个物理对象
2. **合理的时间步长**: 保持在 16.67ms (60fps) 左右
3. **简化碰撞器**: 优先使用基础形状 (球体、立方体)

## 🌟 最佳实践

### 实验设计原则

1. **单一变量**: 每次实验只改变一个参数
2. **对比明显**: 设置明显的对比条件
3. **重复验证**: 多次运行确认结果一致性
4. **记录观察**: 记录关键参数和现象

### 教学应用建议

1. **循序渐进**: 从简单到复杂逐步深入
2. **互动讨论**: 鼓励学生提问和假设
3. **理论结合**: 观察现象后讲解理论
4. **实践验证**: 让学生自己动手实验
